# HerdWise MVC Web Application

HerdWise is a livestock management system built using **ASP.NET Core MVC** and **SQL Server**.  
It was developed as part of a final-year Information Systems and Business Management project.

The system helps farmers digitally manage farms, herds, and herd-related activity in one centralized platform.

---

## 🧠 Project Overview

HerdWise allows users to:
- Create and manage farms
- Create, update, and delete herds within farms
- View herd details and organize livestock data
- Add and manage comments related to herds
- Use a secure authentication system for user access

The goal of the project is to replace manual livestock tracking with a simple, structured, and scalable web-based system.

---

## ⚙️ Features

### 👤 Authentication
- User registration and login
- Secure session-based access
- Logout functionality

### 🌾 Farm Management
- Create new farms
- View and manage existing farms
- Organize herds under specific farms

### 🐄 Herd Management
- Create new herds linked to farms
- Edit herd details
- Delete herds
- View herd information in a structured list

### 💬 Herd Comments (Interaction Feature)
- Add comments to specific herds
- View discussion history per herd
- Supports basic collaboration/notes for herd tracking

---

## 🛠️ Tech Stack

- ASP.NET Core MVC (C#)
- Entity Framework Core
- SQL Server (SSMS)
- HTML5
- CSS3
- JavaScript (basic client-side interactions)
- Git & GitHub (version control)

---

## 🗄️ Database

The project uses **SQL Server** with Entity Framework Core for data access.

Core tables include:
- Users
- Farms
- Herds
- HerdComments
